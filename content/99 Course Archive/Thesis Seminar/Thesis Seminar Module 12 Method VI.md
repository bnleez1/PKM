# Thesis Seminar Module 12: Method VI


💡 On April 17, 2026 11:00 AM, we will discuss [[From Data to Defensible Themes]] about [[Analyzing Qualitative Data]].

## Objectives

### 🎯 Understanding

**Instructors will understand that…**

- Qualitative data analysis is a systematic, documented process that moves from raw data → meaningful units → codes → categories → themes/patterns.

- Coding choices must be aligned with the research questions and the chosen analytic approach (e.g., thematic analysis, content analysis, grounded theory), not simply what is “interesting.”

- Credible qualitative analysis requires transparency: clear code definitions, examples from the data, and a traceable audit trail of analytic decisions.

- Strong analysis connects *evidence* (excerpts/field notes/artifacts) to *analytic claims* (themes/patterns) through explicit reasoning (memos), not just description.

- Trustworthiness can be strengthened through planned strategies (e.g., triangulation, member checking, peer debriefing, negative case analysis) that are integrated into the analysis process.

### 🎯 Language Objective

**Students will be able to…**

- segment qualitative data into meaningful units and apply initial/open codes consistently

- develop and revise a codebook (code name, definition, inclusion/exclusion rules, examples)

- write analytic memos that explain why an excerpt was coded a certain way and how codes are evolving

- combine/refine codes into categories and themes/patterns, with clear criteria and supporting excerpts

- use precise analytic language to describe patterns (e.g., *indicates, suggests, illustrates, appears to*) while avoiding overclaiming
