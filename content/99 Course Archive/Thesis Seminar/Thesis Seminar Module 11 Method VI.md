# Thesis Seminar Module 11: Method VI

## 🎯 Understanding

**Instructors will understand that…**

- Ethical, transparent data collection strengthens the credibility of qualitative and mixed-methods theses.

- A clear, reproducible data-collection procedure (instruments, scheduling, consent, storage) reduces threats to validity/trustworthiness.

- Alignment among research questions, participants, instruments, and analysis plan is necessary before collecting data.

- Data collection and analysis are iterative; early checks (pilots, quality audits) improve the dataset.

---

## 🎯 Language Objective

**Students will be able to…**

- Describe their finalized data-collection procedure using academic, step-by-step language (purpose, participants, instruments, timeline).

- Write a brief “Data Collection” subsection draft that uses appropriate verbs (administer, conduct, obtain, record) and clear sequencing (first, next, subsequently).

- Use conditional and hedging language to state constraints and decisions (e.g., “If participants withdraw…”, “This approach is intended to…”).

## 🎯 Things to Consider…

Review Using Questionnaires within a Qualitative Research Design.

## Key takeaways for including a Likert-scale questionnaire

- Likert items can be included, but only as minor support to an explicitly qualitative design (the primary data and analysis must be qualitative text, not numbers).

- **Use Likert items for** ***context*****, not** ***results***:

    - Brief participant descriptors/background (to help interpret narratives).

    - Routing/branching into deeper open-ended prompts.

    - Identifying information-rich cases for qualitative follow-up (purposeful sampling).

- Pair scale items with qualitative depth:

    - If a Likert item is conceptually important, follow it immediately with an open-ended “why/how/describe an example” prompt.

- Keep them minimal and justified:

    - Use only a few, and justify each item’s qualitative function (context, routing, sensitivity management).

- Avoid “mixed methods drift”:

    - Don’t compute scores, run psychometrics (e.g., reliability, factor analysis), compare groups, or treat distributions/percentages as findings.

    - Don’t let open-ended items become mere “illustrative quotes” appended to a mainly survey-based argument.

- Reporting rule:

    - If you mention Likert responses at all, treat them as background description; your claims should be supported by qualitative analysis (themes, narratives, discourse patterns) of the open-ended responses.
