# How does the TOEFL score relate to the percentage correct?

- Institutional (paper-based) TOEFL scores-to-percentage correct:

    - Listening

        - 400 = 30%

        - 450 = 44%

        - 500 = 62%

        - 550 = 76%

        - 600 = 88%

    - Structure

        - 400 = 43%

        - 450 = 55%

        - 500 = 68%

        - 550 = 80%

        - 600 = 90%

    - Reading

        - 400 = 37%

        - 450 = 48%

        - 500 = 63%

        - 550 = 75%

        - 600 = 87%
