# Three-Tier RTI Template (Expanded Version)

Use this page to document a student’s or teacher trainee’s response to instruction and progressively more intensive support. Base decisions on screening, ongoing assessment, observable evidence, collaboration, and student/family voice.

> **Suggested review cycle:** Review progress every 4–6 weeks, or sooner when the evidence indicates that the intervention should be adjusted.

## Suggested Capacities properties

| Property           | Type                 | Suggested values / purpose                                                                                       |
| :----------------- | :------------------- | :--------------------------------------------------------------------------------------------------------------- |
| Current Tier       | Single select        | Tier 1 - Core Instruction; Tier 2 - Targeted Intervention; Tier 3 - Intensive Support                            |
| Intervention Focus | Multi-select         | Academic Writing; Research Methodology; Language Proficiency; Engagement/Participation; Behavioral/Social; Other |
| Next Review        | Date                 | Date for reviewing progress and deciding whether to retain, modify, advance, or reduce support                   |
| Cohort/Seminar     | Relation or web link | Connect the record to the relevant program, class, cohort, or seminar                                            |
