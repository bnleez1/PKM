# AI prompting tips

- Use action verbs: summarize, synthesize, design, identify, etc.

- Specify format of response: table, list, code, emojis, summary, etc.

- Assign a role: coach, teacher, web designer, etc.

- Specify target audience: clients, business owners, doctors, etc.

- Indicate output criteria or standards: tone, voice, persuasion, etc.
