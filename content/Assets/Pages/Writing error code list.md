# **Instructions**

Oftentimes, the way that I leave feedback on written texts is based on an error code list. Sometimes I will leave only the error code in your an error code list. Sometimes I will leave only the error code in your document, expecting that you reflect, review your class notes, and/or consult the world wide web (i.e., the internet). Other times, I will leave the error code with further explanation. Finally, there will be times when my feedback will only include comments (with no error code

used). Regardless, when you receive feedback in the form of an error code, reflect on the following: 1) What does the error code mean? and 2) How should I correct it? If in doubt, prepare questions that we can address in and outside of class:

- Post a message in the class forum (publicly) so that the entire class can benefit from the question and response. Be assured that if you have a question about anything related to the class, there is at least one other person who has the same question. You are encouraged to post your questions publicly as this is in most cases the best way to handle your doubts.

- Ask questions in class.

- Ask questions personally in class or outside of class.

- Ask questions to your classmates (in class or outside of class).
