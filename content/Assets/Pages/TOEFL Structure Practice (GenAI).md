# TOEFL Structure Practice (GenAI)

[https://u.pcloud.link/publink/show?code=kZeSJ85ZLmrFAJwLy94dG6Wuy6NMzRl36FlV](https://u.pcloud.link/publink/show?code=kZeSJ85ZLmrFAJwLy94dG6Wuy6NMzRl36FlV)

> **Prompt 1**: Create a complete 40-item structure section taken from the TOEFL institutional testing program and include answers to each item. Format the output as a Microsoft Word document so that it can seamlessly be imported to Microsoft Forms and do not provide any explanations with the answers.

Prompt 1 only includes multiple choice where learners indicate the correct response.

> **Prompt 2**: Create a complete 40-item structure section commonly seen for the TOEFL institutional testing program (include both sections) and include answers to each item. Each sentence from each item should be between 18-22 words. Format the output as a Microsoft Word document so that it can seamlessly be imported to Microsoft Forms and do not provide any explanations with the answers.

Prompt 2 causes hallucinations.

> **Prompt 3**: Create a complete 40-item structure section commonly seen for the TOEFL institutional testing program (include both sections) and include answers to each item. Format the output as a Microsoft Word document so that it can seamlessly be imported to Microsoft Forms and do not provide any explanations with the answers.

Prompt 3 better results and Prompt 2, but sentences are still short.

> **Prompt 4**: Create another 40-item structure section commonly seen for the TOEFL institutional testing program (include both sections) and include answers to each item. Make sure each sentence is between 18-23 words. Format the output as a Microsoft Word document so that it can seamlessly be imported to Microsoft Forms and do not provide any explanations with the answers.

Prompt 4 yields 

> Prompt 5: I need a 40-item multiple choice quiz based on the structure section commonly seen for the TOEFL institutional testing program (include both sections) and include answers to each item. Each sentence from each multiple choice question should be between 18-23 words. Format the output and provide an exportable Microsoft Word document so that it can seamlessly be imported to Microsoft Forms and do not provide any explanations with the answers.

Prompt 5 yields good responses.

## Prompt 6

```text
I need a TOEFL institutional testing program that includes both sections of the structure section of the exam. The exam should have 40 multiple choice items and should include the correct answers to each item. Each sentence of each multiple choice item should be between 18-24 words. Format the TOEFL institutional testing program as a Word document that can be inputted directly to Microsoft Forms. Do not provide any further explanations for each item of the TOEFL.
```

## Prompt 7

```text
Analyze the TOEFL institutional testing program and determine all of the different grammatical structures that are being assessed. Create a 60-item TOEFL institutional testing program that contains two parts. Part A should require the user to choose a correct word or phrase while Part B should require the user to identify an incorrect word or phrase. Each item of the TOEFL institutional testing program should be in the form of a multiple choice question and each of the 40 items should have a sentence between 18-24 words. The topics of each item should include topics commonly seen in the TOEFL institutional testing program and each of the 40 questions should include the correct answer. Finally, format the TOEFL as a Word document that can seamlessly be imported directly to Microsoft Forms with no further edits required. Remove any HTML code that indicates underlining text and just leave the plain text.
```

Prompt 7 gets good results using 2.0 Pro (experimental)
