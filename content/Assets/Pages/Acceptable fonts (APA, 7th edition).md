# Acceptable fonts (APA, 7th edition)

Writers being inconsistent with the fonts being used when writing an academic text (i.e., five-paragraph essay, literature review, thesis paper, etc.) This can happen when copying and pasting text from one Word document (usually with a different set of font styles and sizes) to another.

# ✅ Solution

Review the acceptable fonts that are possible according to APA, 7th edition.

• **sans serif fonts** such as 11-point Calibri, 11-point Arial, or 10-point Lucida Sans Unicode 

• **serif fonts** such as 12-point Times New Roman, 11-point Georgia, or normal (10-point) Computer Modern (the default font for LaTeX) ([American Psychological Association - APA)](https://apastyle.apa.org/style-grammar-guidelines/paper-format/font).
