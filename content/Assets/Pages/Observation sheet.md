# Observation sheet

> The following observation sheet is a basic format for describing what goes on in a classroom. This observation sheet should be completed through classroom observation by describing what participants (i.e., students, teachers, etc.) are saying and doing. Then after the observation, an analysis may be conducted that offers an interpretation of what was observed (along with any audio or video recording of the same class). Create a separate observation sheet for each lesson that is being observed.

# Header

Create a header at the top of the page that might include the following: logo, date, hour, teacher's name, name of the school, age of the students, English level, etc. 

# Observation block

> Create an observation block for each stage or activity type. Repeat "Hour:", "Stage/category/activity:", and "Description" for each stage of the class or lesson.
